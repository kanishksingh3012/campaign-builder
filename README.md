# Endcap

A front-end-only prototype of a goal-based ads platform for a quick commerce marketplace: an advertiser picks a goal, gets a bundle of ad formats, and every constraint comes with a one-click fix. Includes a shopper-side search preview with a simple auction simulator.

The brand, the advertisers and every number are fictional and simulated. The one exception is the organic results in the shopper preview, which use real product names and prices from a one-time catalogue snapshot, for learning only. Endcap is not affiliated with any brand or retailer.

New here? Open the Learn page in the app for three short exercises and a plain-language guide to how the auction and the numbers work.

```
npm install
npm run dev
npm test
```
